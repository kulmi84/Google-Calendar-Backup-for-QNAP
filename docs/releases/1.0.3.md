# Google Calendar Backup 1.0.3

Neu: **Testwarnung senden** unter **Sicherung**, neben **Einstellungen speichern**.

- Sendet auf Knopfdruck eine klar gekennzeichnete `Watchdog: TESTWARNUNG` mit Schweregrad **Warnung** an QuLog. Verwendet denselben App-/Watchdog-Präfix wie echte Watchdog-Warnungen.
- Die Testwarnung erscheint als **Testwarnung** in der dauerhaften Fehlerhistorie.
- Die Oberfläche wartet auf die Rückmeldung des QNAP-Protokollwerkzeugs. Bei fehlendem Werkzeug, Fehler oder Zeitüberschreitung erscheint eine Fehlermeldung. Eine fehlgeschlagene Speicherung der Historie wird separat angezeigt.
- Die Bestätigung bedeutet ausschließlich, dass die Meldung an QuLog übergeben wurde. E-Mail/Push hängen von deiner QNAP-Benachrichtigungsregel ab; die App kann deren Zustellung nicht bestätigen.
- Einstellungen, Kalender, ICS-Dateien, letzter Sicherungslauf und Watchdog-Zustand werden durch den Test nicht verändert. Der Test startet keine Sicherung und erzeugt keinen künstlichen Kalenderausfall.

Als Update über QTS App Center manuell installieren. Danach **Testwarnung senden** wählen, in QuLog nach `TESTWARNUNG` suchen und gegebenenfalls den Eingang von E-Mail/Push prüfen. Die Regel muss die Warnungen von Google Calendar Backup berücksichtigen.
