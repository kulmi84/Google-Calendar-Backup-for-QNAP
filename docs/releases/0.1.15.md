## Google Calendar Backup 0.1.15

QNAP application for saving private Google Calendars as timestamped ICS snapshots, with daily scheduling, configurable retention, folder selection and QuLog messages.

### Changes since 0.1.14

- Last backup date and time now use consistent two-digit formatting.
- Added a date-format regression test, German usage documentation and a QTS screenshot.

### Download and install

Requires QTS 5.1.0 or later on x86_64. Download **GoogleCalendarBackup_0.1.15_x86_64.qpkg**, then open **QNAP App Center → Manuell installieren / Install Manually**, select the file and confirm installation. GitHub source archives are not installers.

Launch the application from QTS, configure a secret Google iCal URL and backup destination, then run **Jetzt sichern** and inspect the generated ICS file. Upgrades retain configuration in `/etc/config/GoogleCalendarBackup`.

### Status and limitations

This existing release remains a prerelease. ARM and QuTS hero are not verified. Scheduling uses NAS local time and does not catch up missed runs. Folder selection cannot apply the signed-in user's individual share permissions.

The existing installer includes the application MIT license but lacks the separate bundled Node.js license file; a corrected package is planned for the next version. Do not treat this asset as the corrected build.
